# Creative Strategy Workspace

A ready-to-run creative-strategy workspace for AI coding agents. Research brands, generate ad ideas, write copy and scripts, and learn from every ad you run. AI does the grunt work, you do the thinking.

## Agent-agnostic by design

This workspace works with **any** AI coding agent - not just one. The skills, maps, and workflows are plain markdown files that any agent can read. There is no lock-in to a model, a provider, or a price tag.

**Two paths in:**

- **Paid harnesses** like [Claude Code](https://claude.com/claude-code) or [Cursor](https://cursor.com) - polished IDEs with deep tooling, MCP integrations, and multi-file editing baked in. If you already pay for one of these, use it. The workspace runs the same either way.
- **Free via [opencode](https://opencode.ai)** - an open-source CLI that connects to dozens of models (GPT-4o, Claude, Gemini, Llama, Mistral, DeepSeek, and more) through your own API keys or local inference. You pay only for the API calls you make, and many models have free tiers. No IDE required - just a terminal.

**Why this matters:**

- **Switch models the moment something better drops.** New model releases every week? Change one config line and keep working. Your research, avatars, learnings, and growth guide stay exactly the same.
- **Test models against each other.** Run `/video-copy` on Claude, then on Gemini, then on GPT-4o. See which one nails your brand's voice best. The workspace is the constant; the model is a variable you swap.
- **Start free, upgrade when you want.** opencode + a free-tier API key gets you through onboarding, research, and your first scripts. You never have to pay for a seat you do not need.

The skills do not care which brain is driving. They hand the agent a structured task and the agent executes. That is the whole point.

## Setup

1. Install an AI coding agent - [Claude Code](https://claude.com/claude-code), [opencode](https://opencode.ai), [Cursor](https://cursor.com), or any agent that reads markdown files.
2. Click **Use this template** on GitHub (or clone this repo), then open the folder in your editor or terminal.
3. Open the agent inside that folder and type **`start`**.

That is it. The onboarding interviews you, personalizes the workspace, sets up and verifies your tools, and takes you to your first brand. See `CLAUDE.md` for how everything works, and read `MANIFESTO.md` - it is how we make ads.
