# Creative Strategy Workspace

A ready-to-run creative-strategy workspace for AI coding agents - Claude Code, opencode, Cursor, and more. Research brands, generate ad ideas, write copy and scripts, and learn from every ad you run. AI does the grunt work, you do the thinking.

## Setup

1. Install an AI coding agent - [Claude Code](https://claude.com/claude-code), [opencode](https://opencode.ai), or Cursor.
2. Click **Use this template** on GitHub (or clone this repo), then open the folder in your editor.
3. Open the agent inside that folder and type **`start`**.

That is it. The onboarding interviews you, personalizes the workspace, sets up and verifies your tools, and takes you to your first brand. See `CLAUDE.md` for how everything works, and read `MANIFESTO.md` - it is how we make ads.
